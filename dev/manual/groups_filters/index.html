Groups and Filters

Particle groups are the stable public selection API. The exported Filters module layers higher-level workflows on top of those selections.

Stable selection API

ParticleDynamics.ParticleGroups.ParticleSelection — Type

Abstract base for particle selection specifications.

Concrete subtypes include All, TypeIDs, Indices, and can be extended by users for custom selection logic.

ParticleDynamics.ParticleGroups.ParticleGroup — Type
ParticleGroup

Materialized particle selection containing both host and device indices. Reusable across multiple operations without recomputation.

Instances are created via materialize(selection, state).

ParticleDynamics.ParticleGroups.All — Type

Select all particles.

ParticleDynamics.ParticleGroups.TypeIDs — Type

Select particles by type ID. Accepts a single Int or a vector.

ParticleDynamics.ParticleGroups.Indices — Type

Select particles by explicit list of indices.

ParticleDynamics.ParticleGroups.materialize — Function
materialize(sel::ParticleSelection, state) -> ParticleGroup

Create a reusable materialized group from a selection and state.

ParticleDynamics.ParticleGroups.apply_scalar! — Function
apply_scalar!(dest::CuArray, group::ParticleGroup, value)

Assign value to all elements of dest indexed by group.

ParticleDynamics.ParticleGroups.apply_values! — Function
apply_values!(dest::CuArray, group::ParticleGroup, values)

Assign distinct values per group member.

ParticleDynamics.ParticleGroups.gather — Function
gather(src::CuArray, group::ParticleGroup) -> Vector

Collect values from device array indexed by group onto the host.

ParticleDynamics.ParticleGroups.sum_values — Function
sum_values(src::CuArray, group::ParticleGroup) -> Scalar

Sum values from device array indexed by group.

Typical uses

  • define thermostat baths by particle subset
  • assign temperatures or frictions to selected particles
  • gather subset observables without copying the whole state to host
  • freeze/tether subsets through the higher-level Filters workflows

Notes

  • ParticleGroup is the reusable materialized form.
  • The top-level stable API is the group layer above raw implementation buffers.
  • The Filters module remains the place for freeze controls and stochastic selector-based convenience operations.
