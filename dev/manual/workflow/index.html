Workflow API

The workflow layer describes a simulation with objects: a particle system, groups, forces, an integrator with methods, observables and writers. run! owns the time loop. The Quickstart shows a complete script; this page is the reference for each object.

Simulation and system

ParticleDynamics.Workflow.Simulation — Type
Simulation(system; groups=Groups(), integrator=nothing, observables=Observable[], writers=Writer[], device=nothing, precision=Float64, seed=nothing, metadata=Dict())

Assemble a particle system, groups, integrator, observables and writers into a simulation. Call run! to prepare it and run one or more stages.

ParticleDynamics.Workflow.ParticleSystem — Type
ParticleSystem(data; box, types, typeids, masses, velocities, charges=nothing,
               topology=Topology(), metadata=Dict())

High-level particle/topology container used to build a workflow Simulation. data may be positions directly, an initializer result with .positions/.box, or a GSD frame (whose particles/charge chunk, if present, provides the charges).

charges accepts a length-N vector, a per-type Dict (:Na => 1.0, …), or a scalar, in the caller's charge unit. They are only used by long-range electrostatics forces (PME, PPPM, ESP) and are never inferred from particle types or force-field parameters.

ParticleDynamics.Workflow.Particles — Type
Particles

Alias for ParticleSystem.

ParticleDynamics.Workflow.PeriodicBox — Type
PeriodicBox(lengths)

High-level periodic box descriptor for a workflow ParticleSystem. Supports 2D and 3D boxes.

ParticleDynamics.Workflow.Topology — Type
Topology(; bonds=[], bond_types=[], angles=[], angle_types=[], dihedrals=[], dihedral_types=[],
         impropers=[], improper_types=[], exclusions=[], molecules=[], metadata=Dict())

Topology container used by the workflow API. Each *_types vector is either empty (every tuple carries the label :default) or holds one label per tuple; bonded force descriptors select tuples by these labels. Tuple atom order is kept exactly (it defines angle vertices and torsion signs).

The type-label vectors were added after metadata in the field order. The former 8-argument positional constructor still works and migrates metadata[:angle_types] etc. (as earlier GSD imports stored them).

ParticleDynamics.Workflow.prepare! — Function
prepare!(sim)

Prepare a Simulation for running: validate its configuration, resolve particle groups, initialize forces and dynamics, and set up measurements and output. Call this again after replacing the integrator.

Nonbonded forces

ParticleDynamics.Workflow.Force — Type
Force

Abstract workflow force descriptor. Concrete force objects describe physical interactions to include in an integrator.

ParticleDynamics.Workflow.ForceField — Type
ForceField(; forces=Force[])

Container for a set of workflow force objects.

ParticleDynamics.Workflow.LennardJones — Type
LennardJones(; epsilon, sigma, cutoff, pairs=:all, mode=:standard, pair_table=nothing, neighborlist=nothing, vdw_modifier=:none)

Workflow Lennard-Jones force descriptor. vdw_modifier sets the energy convention at the cutoff: :none truncates, :potential_shift uses u(r) − u(r_c) (the GROMACS default). Forces, virials and dynamics are the same for both; only energies differ.

Workflow Weeks-Chandler-Andersen force descriptor.

Workflow soft-repulsive force descriptor.

ParticleDynamics.Workflow.PairTable — Type
PairTable(; sigma, epsilon, cutoff, type_names)

Per-type parameter table for workflow Lennard-Jones and WCA forces.

Integrator, schemes and methods

ParticleDynamics.Workflow.Integrator — Type
Integrator(; dt, scheme=nothing, forces=Force[], methods=Method[], metadata=Dict(), barostat=nothing)

High-level workflow integrator object. It owns the timestep, force objects, methods, and thermostat-bearing methods that define the simulation dynamics.

ParticleDynamics.Workflow.VelocityVerlet — Type

VelocityVerlet() selects the workflow velocity-Verlet stepping scheme.

ParticleDynamics.Workflow.BAOAB — Type

BAOAB() selects the workflow BAOAB Langevin splitting.

ParticleDynamics.Workflow.BAOA — Type

BAOA() selects the workflow BAOA Langevin splitting.

ParticleDynamics.Workflow.GSM — Type

GSM() selects the workflow Grønbech-Jensen/Farago style scheme.

ParticleDynamics.Workflow.EulerHeun — Type

EulerHeun() selects the workflow Brownian midpoint scheme.

ParticleDynamics.Workflow.EulerMaruyama — Type

EulerMaruyama() selects the workflow Euler-Maruyama scheme.

ParticleDynamics.Workflow.Method — Type
Method

Abstract workflow method applied to a Group.

ParticleDynamics.Workflow.ConstantVolume — Type
ConstantVolume(group; thermostat=nothing)

Molecular-dynamics method for a particle group, optionally coupled to a workflow thermostat. When thermostat === nothing, the group evolves in the microcanonical NVE limit.

ParticleDynamics.Workflow.Langevin — Type
Langevin(group; gamma, kT)

Langevin method applied to a workflow group.

ParticleDynamics.Workflow.Brownian — Type
Brownian(group; gamma, kT)

Brownian dynamics method applied to a workflow group.

ParticleDynamics.Workflow.ActiveOrnsteinUhlenbeck — Type
ActiveOrnsteinUhlenbeck(group; gamma, tau=nothing, noise_scale=nothing, spectrum=nothing)

Active Ornstein-Uhlenbeck method applied to a workflow group. This method only configures the correlated OU process. Thermal white noise is controlled separately through Brownian or Langevin, so a thermal AOUP model is built by assigning both methods to the same group.

The active OU amplitude is set by noise_scale or by the scales stored in spectrum. Those values are stationary standard deviations of the OU impulse, not bath temperatures.

ParticleDynamics.Workflow.OUSpectrum — Type
OUSpectrum(taus, scales)

Multi-mode Ornstein-Uhlenbeck spectrum used by ActiveOrnsteinUhlenbeck.

ParticleDynamics.Workflow.Thermostat — Type
Thermostat

Abstract workflow thermostat descriptor.

ParticleDynamics.Workflow.CSVR — Type
CSVR(; kT, tau)

Canonical stochastic velocity-rescaling thermostat.

ParticleDynamics.Workflow.NoseHooverChain — Type
NoseHooverChain(; kT, tau, chain_length=5, substeps=4)

Nose-Hoover chain thermostat descriptor for the workflow API.

Barostats are passed as Integrator(...; barostat=...), see Bonded Terms, Minimization and NPT.
