Install and begin

Simulations run on a CUDA-capable NVIDIA GPU. Use Julia 1.11 or later with a working CUDA installation, then install the registered package:

using Pkg
Pkg.add("ParticleDynamics")

These are the development docs for 0.7.0; the registered release may differ. The first simulation walks through the setup and a complete run. All physical quantities use a consistent set of units chosen by you.

From a model to a measurement

A ParticleSystem holds your initial configuration. Forces describe its interactions; an Integrator sets the dynamics and timestep. Add observables and writers, assemble a Simulation, and run named stages for equilibration and production.

# With your system, integrator and writers defined:
sim = Simulation(system; integrator=integrator, writers=writers)
run!(sim, Stage(:equilibrate, steps=1_000))
reset_observables!(sim)
run!(sim, Stage(:production, steps=10_000))

Learn how to choose interactions, control temperature, and record measurements.

Supported systems

ParticleDynamics supports 2D and 3D periodic systems on a single GPU, including Lennard-Jones, WCA and soft-repulsive interactions, bonded models, Langevin and Brownian dynamics, and active Ornstein–Uhlenbeck forcing. Energy minimization and isotropic pressure control are also available.

Long-range electrostatics requires a 3D orthorhombic periodic box. Pressure control has specific integrator requirements, described in the bonds, minimization and pressure guide. General holonomic constraints beyond rigid three-site water, triclinic electrostatics and multi-GPU execution are not implemented.
